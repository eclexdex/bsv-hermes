# Source and dependency policy

This distribution contains original prototype implementation and synthetic fixtures, not vendored third-party SDK source. Hermes is the separately installed host; Python's standard library is the only runtime dependency. Setuptools is build tooling, not a runtime dependency.

The unified package incorporates reviewed original base, identity, assurance and integration domain implementations. Their versioned commitment formats are preserved. Public attribution, copyright holder and release license remain pending operator approval. Candidate MIT declarations from staged prototype packaging were **not adopted**: no family-wide release grant had been approved. This is a metadata policy correction, not a change to immutable upstream evidence or a claim that third-party licensing restrictions disappeared.

No upstream research mirror, SDK archive, private evidence, workstation acceptance helper, wallet data or live profile is included. A future SDK bridge needs its own pinned source/export/license review. Source availability alone does not grant redistribution rights. See LICENSE-POLICY.md.
